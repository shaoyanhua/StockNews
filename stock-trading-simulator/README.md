# 练盘 · 真实行情回放交易台

当前版本使用 **2026 年 11 月 12 日** 的真实分钟行情，替换原来的随机行情网页。11 只证券每只 240 根分钟 K 线，另含上证、深证、创业板指数及逐分钟市场涨跌家数。数据已打包到本地，可离线回放；不是持续推送的实时行情。

## 打开与操作

- 双击 `启动模拟盘.cmd`，启动后自动打开 <http://127.0.0.1:5188>。需要 Node.js，无需安装 npm 依赖。
- 或直接双击 `dist/index.html`。浏览器对本地文件存储的支持可能不同，推荐使用上面的启动方式。
- 命令行运行 `npm start`，按 Ctrl+C 停止；端口默认 5188，可通过 `PORT` 环境变量修改。
- 打开后从 **09:30** 开始，点击「开始回放」，或「＋1 分钟」「＋5 分钟」。1× 每秒推进 1 个交易分钟，可改为 5× / 15×。
- 「推进至收盘」会依次处理余下分钟与挂单，不直接跳价；15:00 后结束本轮。重新开盘恢复预置账户。
- 选择证券后，股票默认下单 100 股，ETF 默认 10,000 份；可改数量或使用分仓按钮。持仓表可直接切换买卖。交易计划可展开填写。
- 图表可切换分时 / 5 分钟 K 线、放大已走区间 / 全天坐标。鼠标悬停显示该分钟价格、均价、成交量、成交额；买卖点以 B / S 标记。

## 信息与指标

| 信息 | 口径 |
| --- | --- |
| 分时 / 5 分钟 K 线 | 实际分钟 OHLC 聚合，只包含已回放的分钟，最后一根 5 分钟线可能未完成 |
| 成交量 / 成交额 | 分钟实际股 / 份数、人民币金额累计 |
| 分时均价 | 累计成交额 ÷ 累计成交量 |
| 量比（估） | 当前每分钟平均量 ÷ 前 5 个交易日每分钟平均量；前 5 日不含今天 |
| 5 分钟量能比 | 最近 5 分钟量 ÷ 前 5 分钟量；不足 10 分钟或分母为零显示 — |
| 换手（估） | 当前累计成交量 ÷ 当日快照推算的流通规模 |
| 振幅 / 5 分钟涨速 | 已回放高低差 ÷ 昨收；当前价相对 5 分钟前价格的变化 |
| 沪深情绪温度 | 当前分钟上涨家数 ÷（上涨＋下跌家数），不含平盘和北交所 |
| 自选情绪 | 11 只证券上涨 / 下跌数量、平均涨跌幅、站上分时均价数量 |
| 相对持有收益 | 当前总资产 − 同一初始组合一直不交易时的资产 |

情绪温度阈值：<30% 偏冷、30–45% 偏弱、45–55% 分歧、55–70% 偏强、≥70% 偏热。它是市场广度描述，不是预测胜率。市场广度只加总沪市与深市，不重复叠加创业板。量价标签也是已发生事实的描述，不是投资建议或自动交易信号。

每个标的验证 09:31–11:30、13:01–15:00 共 240 分钟，检查唯一时间序列、OHLC、收盘价、高低价、累计量额及 5 日基准日期。原始分钟量与收盘报价的累计量最多差 104 股 / 份，保留原值；成交额有浮点汇总尾差，未补造或按比例篡改分钟数据。

## 撮合、费用与统计

交易为模拟：市价按当前可见价格加 / 减一个报价单位成交，限价在后续分钟收盘对手价达到条件时整笔成交。不会用当前分钟已经过去的高低点让新挂单成交。没有历史逐笔盘口、排队、部分成交、冲击成本或真实集合竞价撮合。

买单冻结资金，卖单冻结可卖数量，15:00 未成交单失效。训练限价边界：创业板股票及科创芯片 ETF ±20%，其余 ±10%；封涨停不买、封跌停不卖。这是简化训练模型，不覆盖全部真实规则。

默认佣金万 2.5、最低 5 元，股票卖出印花税万 5、双向过户费万 0.1；ETF 不收后两项。实际费率以券商为准。持仓按含买入费用的加权平均成本计算；卖出费计入已实现盈亏。胜率按已成交卖出笔数统计，最大回撤按昨收基准及随后净值更新。
